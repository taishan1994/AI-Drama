# 《如果累了就回故乡》分镜与视频 Prompt v1

## 制作依据

- 音源：`素材/音频/如果累了就回故乡_少年版_酷酷里-面妹孔佳奇.mp3`，230.713 秒，44.1 kHz 双声道 MP3。
- 歌词/段落时码：根据用户给定歌曲页的播放器 LRC 预览整理；以下是剪辑规划时码，不替代对本地音轨逐句听校。声画最终剪点允许随实际重拍、换气和尾音微调。
- 叙事：童年村庄 → 成年城市疲惫 → 决定返乡 → 与奶奶重逢 → 走过旧日地点 → 夜归安歇。始终是一条连续故事，不做无因果的风景拼贴。
- 暂定视觉方向：适配童声、温柔怀旧的乡村流行抒情气质，采用电影构图的手绘绘本动画：细腻水粉/彩铅质感、柔和自然光、生活化微表情、克制的镜头运动；城市段降低饱和与对比，返乡后渐暖。不是默认上美影仿制，也不是逐镜换风格。先做风格定稿图，再据此锁定全部角色与场景资产。
- 视频生成画面不含歌词、字幕、对白、旁白或自带音乐；后期只铺本地确认的歌曲音轨与按最终混音校准的歌词字幕。

## 风格与声音判断

从已锁定版本的童声演唱定位、歌词意象和本地音频的约 89 BPM 节拍估计，视觉围绕清澈童声、乡村日常和“漂泊—回家—松下来”的情绪弧线组织；正式定稿前仍需人工完整试听，确认旋律起伏、乐器层次和转折后再微调。画面不让主角对口型，不把童年与成年主角变成同时存在的现实人物。较舒缓段落以缓推、横移、跟随步伐为主；重复副歌不复制完全相同的镜头，而是推进返乡与关系变化。避免卡点式快速剪辑、夸张喜剧表演、过度梦幻粒子和商业广告式高饱和质感。

## 连续性锁定

- 主角：林小满成年版约 25 岁，深棕齐肩发、偏瘦、灰蓝通勤外套、米色帆布包；童年版约 8 岁，短发、鹅黄上衣、砖红围巾。两年龄版必须从角色资产锁定脸型、眉眼、鼻形和发色的家族相似性。
- 奶奶：约 65 岁，银灰发髻、靛蓝头巾、深棕布衣、温和但不过度笑脸；从院中出门接小满，始终走同一条村路。
- 唯一贯穿道具：一只红纸风车；最初由童年小满持有，成年后收在帆布包内，返乡后修好，最后放在窗边。不得复制、漂移或无故消失。
- 固定空间图：老屋院门连村巷；村口老槐树在巷道尽头；田埂从村口向远山延伸；小溪在田埂左侧低处。城市办公室与车站不与村庄混切；沿途方向保持一致。
- 每个相邻镜头使用上镜验收尾帧作下一镜首帧。切镜前后各检查 3–5 帧：人物尺度与朝向、风车所在手/位置、行进方向、背景锚点、镜头运动、光线连续。避免轻微漂移造成“卡一下”。
- 声音：H3 镜头生成时关闭自带音频/音乐；成片只用上述 MP3，不额外合成唱声、对白、旁白或环境人声。环境声若要使用，需另行设计并确认；本版建议先不叠环境声，以保持歌曲干净。
