# 《极乐净土》舞蹈参考拆分

参考视频：`素材/舞蹈参考/极乐净土_三人原编舞参考.mp4`，约 225 秒。

## 使用方式

- 只参考原编舞的节拍、队形、手臂路径、重心变化和镜头节奏。
- 不复制原舞者的脸、服装、背景或真人影像。
- 生成时始终替换为本项目三位舞姬：左侧粉白、中央红黑、右侧紫蓝。
- 每个 H3 片段控制在 5–8 秒，动作只选择一个完整动作链，避免模型在一个片段内跳太多动作。

## 动作段落标记

| 参考时间 | 动作要点 | 生成用途 |
|---|---|---|
| 0:00–0:08 | 低姿态起势，三人形成层次 | 片头显现、静止到第一拍 |
| 0:08–0:25 | 同步抬臂、开肩、左右重心移动 | 第一段基础群舞 |
| 0:25–0:45 | 横向移动、手臂展开、队形保持 | 江户街场景 |
| 0:45–1:10 | 更大幅度甩袖、抬腿、同步定格 | 第一副歌 |
| 1:10–1:35 | 轮流领舞，另外两人保持陪衬动作 | 樱花庭院变化 |
| 1:35–2:05 | 动作放慢、身体起伏和袖摆延迟 | 镜面水庭间奏 |
| 2:05–2:45 | 快速手部动作、短暂停格、重拍定点 | 霓虹鸟居副歌 |
| 2:45–3:15 | 三角队形、轮流前进、中心舞姬领舞 | 法阵桥段 |
| 3:15–3:45 | 三人同步高潮、转身、最终定格 | 极乐净土终章 |

## 第一镜头锁定

- 资产：三张角色四视图、三舞姬固定站位图、黑金赤月鸟居空场。
- 首帧：`资产/关键帧/S01_黑金赤月舞台_三舞姬静止起势_首帧_v1.png`
- 动作：从静止起势开始，三人同时抬手至胸前，再向两侧展开；中央舞姬先完成轻微转肩，左右舞姬延迟半拍跟随。
- 禁止：换位、交叉、额外舞者、镜头突然翻转、自动字幕、对白、旁白和人声。
