# 《极乐净土》MV 重制 v2 分镜设计

## 总规则

本版的动作来源只有 `素材/切分_v2/舞蹈视频/Sxx_*.mp4`。每个分镜必须加载同编号舞蹈视频，逐帧跟随三位舞姬的真实动作、节拍、步伐、手臂轨迹、重心和停顿；禁止用文字动作描述替代视频参考，也禁止引用未切分的整段舞蹈视频。

舞蹈视频自带的音频是该分镜唯一音乐参考。H3 生成的声音全部丢弃，验收通过后从同编号舞蹈分段中直接提取音频，和生成画面复合。

每个镜头固定：三位舞姬、粉色左侧、红黑中央、紫色右侧；人物身份、脸、发饰、服装和体型沿用角色设定板；目标环境沿用环境设定板；首帧承接上一镜尾帧。参考视频中的白色摄影棚、真人、原服装、黑色剪影和音频均不得进入最终画面。

## H3 统一生成约束

`<Video 1>` 必须是当前镜头同编号的切分舞蹈视频。只提取其中三位舞者的逐帧动作与节奏，生成三位目标舞姬；禁止复制参考视频的真人、白色摄影棚、原服装和原背景。画面必须始终有目标环境，人物不得变黑、消失、增减或互换。生成结果静音保存，最终音频从同编号切分舞蹈视频提取。
