# 极乐净土重制 v2：舞蹈与音乐时间轴

源文件：`极乐净土_三人原编舞参考.mp4`

- 舞蹈视频画面和其自带音频使用同一时间切点。
- 生成视频时，舞蹈分段只作为动作与节奏参考；H3 生成的音轨不作为成片音轨。
- 每个通过验收的生成片段，最终直接复用对应舞蹈分段的原音频，因此舞蹈和音乐不会漂移。
- 原视频总长约 225.173 秒；成片时间轴按音乐有效时长约 218.546 秒结束，最后一段为 216–218.546 秒。
- 共 28 段：S01–S27 为 8 秒，S28 为最后剩余段。

## 验收门槛

每段必须同时满足：

1. 动作轨迹与同编号舞蹈分段相符；
2. 三位舞姬保持固定身份、服装与颜色，不能变黑、互换或增减；
3. 目标背景始终存在，不能变白或被原舞蹈摄影棚替换；
4. 通过后才复制到 `视频/final_v2/`；未通过片段不得进入最终合成。
