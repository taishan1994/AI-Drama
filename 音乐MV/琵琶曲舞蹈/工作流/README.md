# 深度黑白视频工作流

**当前有效版本请看 [深度图说明.md](深度图说明.md)，导入 `ComfyUI_视频转深度图.json`。以下为弃用的黑白滤镜实验，不符合白模深度参考图。**

输入视频默认为 `../素材/7621879784973062134.mp4`，输出到 `../处理/深度黑白/`，保留原视频音频。

```bash
python3 深度黑白视频.py
```

也可以指定输入和输出：

```bash
python3 深度黑白视频.py --input /path/input.mp4 --output /path/output.mp4
```

处理链为：去饱和 → 轻度模糊抹平纹理 → 强对比 → 四级灰阶量化。人物会接近白模块面，脸部、衣料和小道具细节被压掉；分辨率和帧率保持原视频设置。
