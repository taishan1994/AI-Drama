# 768p 纯文生视频：情绪强化版，无说话声

以 `文生视频/480p测试/成片/文生视频_480p_情绪强化_00001_.mp4` 的表现为主，沿用同一份情绪强化 prompt 与随机种子，改为 1344×768 输出。保留 H3 音频解码节点，声音提示保留自然呼吸、吞咽、与画面相符的抽泣或哭声，以及轻微户外风声和衣料摩擦；只排除说话、台词、耳语、旁白、哼唱和可辨识的语言声。

## 成片

- 成片：`成片/人物表情_MinimaxH3_T2V_768p_情绪强化_自然环境声无说话声_24fps.mp4`
- 预览：`成片/预览.jpg`
- 规格：1344×768、24 fps、12.25 秒；H.264 视频、AAC 立体声音轨

## 可复现文件

- Prompt：`人物表情_强化情绪_768p_自然环境声无说话声_prompt.txt`
- ComfyUI 工作流：`工作流/人物表情_T2VA_768p_情绪强化_无额外人声_API.json`
- 渲染脚本：`工作流/render.py`
- 成功运行记录：`工作流/history.json`
- 使用 MiniMax H3 FL2VA，8 步采样。文本编码器放在第二张 GPU 上，以避开第一张 GPU 的显存不足。
- 用本地 Whisper large-v3-turbo 检查成片音轨，未检出可辨识对白。
