# 镜界·武戏 — 动作指导系统

## 核心规则

1. **本技能仅在动作场景中激活**。判断标准：场景中包含明确的打斗、格斗、追逐、兵器交锋、法术对决等肢体冲突或高强度运动。非动作场景（文戏、对话、情感戏）不触发。
2. **每个动作必须分解为5个阶段**（起始→发力→接触→受力→结束），确保物理真实感。禁止跳过任何阶段。
3. **所有动作必须符合人体工学和物理逻辑**。出拳需转腰、踢腿需支撑、跳跃有起落。禁止违反重力、惯性、动量守恒的动作（除非为奇幻/仙侠设定且有能量特效支撑）。
4. **环境互动是强制要求**。动作必须与环境产生可观察的互动效果（踢起尘土、撞碎桌椅、踩裂地面等）。
5. **特效服务于动作，不喧宾夺主**。特效强度必须与动作力度匹配，禁止无中生有的视觉效果。

## 触发条件

本技能在以下条件之一满足时激活：

- 用户选择**方案G（打斗特效版）**
- 用户开启了**动态动作增强**
- 智能体判断当前S-Block为**动作场景**（功能类型标记为"爆发型"或内容含打斗/格斗/追逐）
- 概要规划中**识别动作场景**字段标记为"是"

**不触发的情况**：
- 文戏场景（对话、情感、内心戏）
- 仅含轻微肢体语言的场景（如握手、拥抱）
- 氛围/意境场景
- 纯空镜镜头

## 决策流程

面对任何动作场景，按以下顺序应用：

### 第一步：动作分解（武术指导模块）

每个动作拆解为5个阶段，逐阶段描述：

| 阶段 | 描述要点 | 示例 |
|------|---------|------|
| 起始 | 蓄力姿态、重心转移、肌肉紧绷 | "双脚微沉，右腿后撤半步，腰腹收紧" |
| 发力 | 力量爆发点、肢体轨迹、速度变化 | "转腰带动右臂，拳面直冲对方胸口" |
| 接触 | 打击点精确、受力部位形变 | "拳面撞上胸口，衣料瞬间凹陷震开" |
| 受力 | 被击打者反应（后仰/踉跄/护痛/表情痛苦） | "身体后仰，双脚离地向后滑行" |
| 结束 | 收势、喘息、调整站位 | "拳收回腰间，深吸一口气，重心微调" |

### 第二步：节奏控制（节奏引擎模块）

- **镜头时长**：关键打击点用慢镜头（升格）或定格强化，过渡动作用快速剪辑
- **呼吸帧**：在激烈动作后插入0.5-1秒的"呼吸帧"（双方对峙喘息、道具静止、环境声突显）
- **音画同步**：打击声、破风声与动作帧精确对齐

### 第三步：导演调度（导演模块）

- **多角度呈现**：同一动作从不同机位展现（正面特写打击点 + 侧面全景展示位移）
- **环境互动**：动作必须与环境产生可观察的互动效果
- **道具追踪**：武器/道具在运动中轨迹连贯，与手部位置严格匹配

### 第四步：特效加持（特效师模块）

- **物理特效**：打击点生成冲击波、火星、碎片，根据受力强度变化
- **能量特效**：奇幻设定下加入灵力光效、残影、轨迹线，符合能量释放逻辑
- **粒子系统**：尘土、水花、落叶等环境粒子与动作互动

### 第五步：协同校验（强制执行）

每组动作镜头输出前，必须通过以下校验：

| 校验项 | 规则 | 不通过处理 |
|--------|------|-----------|
| 逻辑一致性 | 攻击后必有防守或位移，禁止敌人傻站挨打 | 调整动作序列 |
| 道具连续性 | 道具在镜头切换时位置、状态保持一致 | 修正道具状态 |
| 视线连续性 | 角色视线方向在正反打中匹配 | 调整视线方向 |
| 能量守恒 | 特效强度与动作力度匹配 | 弱化或强化特效 |

## 与其他 Skill 的协作

- **景别库**：动作场景优先使用特写/大特写（打击点）+ 远景/全景（位移展示），景别快速切换制造节奏
- **构图库**：动作场景优先使用对角线/引导线构图，制造张力和动感
- **运镜库**：动作场景优先使用手持晃动、快速推拉、跟拍、低角度跟拍、急速甩镜
- **转场库**：动作场景优先使用硬切、甩镜头转场，节奏紧密
- **空镜系统**：动作场景一般不大量使用空镜，但可用于"呼吸帧"调节节奏。若动作场景涉及内容安全（如过度血腥），可使用空镜做暗示性替代
- **内容安全**：动作场景自动触发内容安全预检，血腥画面优先用空镜暗示替代直接展示

## 镜头数量约束

- 方案G（打斗特效版）：每组强制 **3-9个** 有效叙事镜头
- 动态动作增强开启时：每组 **3-6个**（非G方案标准）
- 因动作分解需要增加镜头时，可突破上限，但需在概要中标注"因动作分解临时突破"
