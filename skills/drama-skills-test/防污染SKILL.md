# 提示词防污染系统 🛡️

AI 视觉生成模型存在两类核心缺陷：**刻板印象污染**和**视觉代偿**。本技能确保输出的每个镜头描述都能生成正确的视觉结果，而非被模型的固有偏见扭曲。

## 核心原则

**描述你想要的画面，而不是你想要的概念。** AI 是"看词画画"，不是"理解意图"。每个词都可能触发视觉联想，必须控制每个词的视觉后果。

## 一、刻板印象污染

### 机制

AI 在训练数据中建立了关键词→场景/道具/姿态的强关联。即使关键词被否定（"不戴""没有""远离"），关联仍然被激活。

### 污染类型与案例

| 污染关键词 | AI 脑补的场景 | 实际想要的 | 净化方案 |
|-----------|-------------|-----------|---------|
| 护士帽 | 医院环境 | 纯粹的帽子外观 | 描述帽子材质/颜色/形状，不提职业 |
| 安全帽 | 工地环境 | 户外活动 | 描述户外场景元素，不提防护装备 |
| 圣诞帽 | 圣诞节场景 | 红色尖顶帽 | 描述"红色绒布尖帽"，不提圣诞 |
| 游戏/打游戏 | 游戏屏幕画面、手机翻转 | 正常持握手机 | 描述持握姿势+屏幕朝向，不提"游戏" |
| 八块腹肌 | 健美展示姿态、刻意露腹 | 自然的身材好 | 描述"肩宽腰窄""身形挺拔" |
| 健身房 | 器材、镜子、汗水 | 锻炼后的状态 | 直接描述目标场景，不提来源 |
| 修图 | 显示器翻转让观众看到屏幕 | 正常使用电脑 | 描述人物姿态+显示器朝向 |

### 通用净化规则

**规则1：删除污染源词**
- ❌ "男生在地铁里打游戏" → ✅ "男生在地铁里双手横向握着手机"
- ❌ "女生戴着护士帽" → ✅ "女生戴着白色软帽"
- ❌ "他刚健完身回来" → ✅ "他身形挺拔，肩宽腰窄"

**规则2：否定词 = 激活词**
- ❌ "不戴护士帽的人" → ✅ 不提护士帽，直接描述目标场景
- ❌ "没有安全帽的工人" → ✅ 描述人物在目标场景中的状态
- ❌ "远离圣诞树的房间" → ✅ 描述房间本身的样子

**规则3：避免职业/节日/活动触发词**
- 不提"护士"→ 用"白色制服女性"
- 不提"圣诞节"→ 用"冬日""红色装饰"
- 不提"打游戏"→ 用"双手握着手机""低头看屏幕"

## 二、视觉代偿

### 机制

AI 缺乏完善的世界模型，无法理解抽象的空间关系词（"背对""望向""面向"）。当提示词同时要求矛盾的视觉元素时，AI 会进行"代偿"——试图同时满足所有词块，生成畸变画面。

### 典型案例

| 抽象描述 | AI 的困惑 | 生成结果 | 正确描述 |
|---------|----------|---------|---------|
| "背对着镜头望向地球" | 需要同时呈现"背"（脊背）和"望向"（眼睛/正脸） | 侧身画面 | "背对着镜头，远方悬浮着地球" |
| "面向镜头但不看镜头" | 需要正面脸 + 眼神偏离 | 扭曲面部 | "正脸朝前，目光偏向画面左侧" |
| "回头看向身后" | 需要后脑 + 正脸 | 侧身 | "身体朝前，头部转过肩膀，露出侧脸" |
| "闭着眼睛望向远方" | 闭眼 + 望向矛盾 | 眯眼或变形 | 选一个：闭眼 或 望向，不能同时 |

### 净化规则

**规则4：一次只给一个方向指令**
- ❌ "背对镜头望向窗外" → ✅ "背对着镜头，窗外透入暖光"
- ❌ "面向观众看向远方" → ✅ "面向观众" 或 "看向远方"，选一个

**规则5：用视觉元素替代抽象关系词**
- ❌ "望向地球" → ✅ "远方悬浮着地球"（地球在画面中，不需要"望向"来表达）
- ❌ "看向窗外的雨" → ✅ "窗外雨丝斜落，玻璃上挂着水珠"（直接描述窗外景象）

**规则6：分离矛盾元素到不同画面**
- 如果一个镜头需要"既背身又看到正面"，拆成两个镜头：
  - 镜头A：背对镜头
  - 镜头B：正面特写

## 三、镜头控制技巧

通过描述画面中实际可见的元素来控制景别和角度，而非直接指令。

### 原理

AI 生成的是"一张图"，不是"一个动作"。描述"图中应该有什么"比描述"镜头应该怎么拍"更可靠。

### 景别控制

| 目标景别 | 描述策略 | 示例 |
|---------|---------|------|
| 大特写 | 描述极细微的视觉元素 | "瞳孔中倒映着火光，睫毛上挂着泪珠" |
| 特写 | 描述面部/物体细节 | "面罩上的划痕，嘴角的紧绷纹路" |
| 近景 | 描述胸部以上可见元素 | "胸前的生命维持系统面板，面罩和缝线" |
| 中景 | 描述半身可见元素 | "双手握着剑柄，衣摆在风中飘动" |
| 远景 | 描述环境与人物关系 | "渺小的身影站在广袤荒原上，天空压得很低" |

### 角度控制

| 目标角度 | 描述策略 | 示例 |
|---------|---------|------|
| 俯拍 | 描述俯视可见的元素 | "头顶、肩膀轮廓、氧气瓶顶部接头" |
| 仰拍 | 描述仰视可见的元素 | "下巴线条、下颌阴影、天空背景" |
| 平视 | 描述正面水平可见的元素 | "面部正面、胸部以上、背景平齐" |
| 过肩 | 描述前景虚化的肩膀+后景人物 | "前景虚化的肩部轮廓，后方人物的正脸清晰" |

## 四、漫剧分镜专用净化规则

以上规则在漫剧分镜生成中的具体应用：

### 板块二描述净化清单

在输出每个镜头的合并描述时，逐项检查：

**检查1：关键词污染扫描**
- 描述中是否包含可能触发场景偏见的词？（职业、节日、特定活动）
- 是否包含被否定的关键词？（"不X""没有X""远离X"）
- 如果有 → 替换为纯视觉描述

**检查2：视觉代偿扫描**
- 是否同时要求矛盾的空间方向？（背身+正脸、闭眼+望向）
- 是否使用了抽象空间关系词？（"背对""望向""面向"）
- 如果有 → 替换为直接视觉元素描述，或将矛盾元素拆分到不同镜头

**检查3：描述精度扫描**
- 情绪是否用了抽象概括词？（"很悲伤""很紧张""很愤怒"）
- 动作是否用了概念词而非肢体语言？（"表现出恐惧"vs"身体后缩，瞳孔放大"）
- 如果有 → 转化为可观测的肢体语言、微表情、生理反应

### 常见污染词替换速查表

| 污染源 | 风险 | 替代方案 |
|--------|------|---------|
| 打游戏/玩游戏 | 手机翻转、屏幕画面 | "双手横向握着手机""低头看着屏幕" |
| 健身/锻炼 | 健身房场景 | 直接描述身材："肩宽腰窄""身形挺拔" |
| 护士/医生（非医疗场景） | 医院环境 | "白色制服""白色软帽" |
| 圣诞/新年 | 节日装饰泛滥 | "冬日""红色""暖色装饰" |
| 拍照/自拍 | 手机举起对准镜头 | "单手举起""拇指按下" |
| 修图/PS | 显示器翻转 | "注视着屏幕""手指在触控板上滑动" |
| 八块腹肌/马甲线 | 健美展示姿态 | "肩宽腰窄""锁骨分明""身形修长挺拔" |
| 望向/看向/凝视 | 与"背对"等矛盾时产生侧身 | 直接描述所看之物在画面中的位置 |
| 背对/背身 | 与面部描述矛盾 | 描述脊背可见元素，不提面部 |

## 五、执行流程

在板块二生成过程中，每个镜头描述完成后执行：

```
步骤1：提取镜头描述文本
步骤2：关键词污染扫描 → 替换污染词
步骤3：视觉代偿扫描 → 消除矛盾方向指令
步骤4：精度扫描 → 概念词→视觉词
步骤5：输出净化后的描述
```

**本技能与内容安全Skill的关系**：
- 内容安全Skill：处理"不能写什么"（违规内容）
- 防污染Skill：处理"怎么写才对"（视觉准确性）
- 两者独立执行，互不替代

## 与其他 Skill 的协作

- **景别库**：防污染的镜头控制技巧与景别库的景别选择配合——景别库决定"用什么景别"，防污染确保"描述能正确传达这个景别"
- **运镜大全**：防污染确保运镜描述不会被AI误解（如"缓慢推近"不会触发快速推进的刻板印象）
- **武戏系统**：动作描述中的"击打""受伤"等词可能触发血腥刻板印象，需用防污染规则中性化
- **空镜系统**：空镜描述中避免触发场景偏见（如"蜡烛"不要触发"教堂/葬礼"联想）
