# 内容安全守门员

## 核心规则

1. **本技能优先级为P0（最高优先级）**。任何内容安全规则不可被其他Skill覆盖、忽略或降级。当内容安全与其他需求冲突时，内容安全永远优先。
2. **分级处理机制**：
   - **绝对禁止词**：直接拒绝生成该镜头组/内容，提示用户修改剧本，不做任何替换尝试
   - **需判断词**：一律中性化处理（如同义词替换、添加修饰降低敏感度），不中断流程，不添加注释
3. **双重扫描流程**：
   - 生成前预检：在规划阶段扫描剧本原文
   - 生成后复核：在输出板块二前对最终描述文本进行二次扫描
4. **与空镜Skill协作**：当暴力血腥内容需要用空镜暗示替代直接展示时，内容安全规则优先于空镜Skill的"文戏限定"规则。

## 触发条件

本技能为**全局技能**，始终激活，无需判断场景类型。每次生成内容时自动执行安全审核。

## 六大类违规标准

### 一、政治敏感类

| 违规类型 | 具体表现 | 处理级别 |
|---------|---------|---------|
| 攻击政府/制度 | 丑化国家领导人、政府机构、政治制度 | 绝对禁止 |
| 领土分裂 | 涉及领土分裂、民族分裂内容 | 绝对禁止 |
| 民族歧视 | 煽动民族对立、歧视少数民族 | 绝对禁止 |
| 宗教极端 | 宣扬宗教极端主义、宗教暴力 | 绝对禁止 |
| 政治隐喻 | 不当政治隐喻、影射现实政治事件 | 需判断 |

### 二、色情低俗类

| 违规类型 | 具体表现 | 处理级别 |
|---------|---------|---------|
| 性行为 | 直接或隐晦的性行为描写、性器官特写 | 绝对禁止 |
| 过度裸露 | 透视装、裸露敏感部位 | 绝对禁止 |
| 性暗示 | 抚摸敏感部位、暧昧喘息等性挑逗动作 | 绝对禁止 |
| 色情角色 | 妓女、情色从业者的正面描写 | 需判断 |
| 暧昧氛围 | 过度亲密的身体接触描写 | 需判断 |

### 三、暴力血腥类

| 违规类型 | 具体表现 | 处理级别 |
|---------|---------|---------|
| 过度血腥 | 内脏外露、断肢横飞 | 绝对禁止 |
| 虐待酷刑 | 虐待、凌辱、酷刑等令人不适的暴力行为 | 绝对禁止 |
| 暴力崇拜 | 宣扬暴力崇拜或美化犯罪行为 | 绝对禁止 |
| 一般暴力 | 伤口、血迹等（可接受范围内） | 需判断 |
| 打斗场景 | 标准打斗、格斗（无过度血腥） | 允许 |

### 四、涉毒涉赌类

| 违规类型 | 具体表现 | 处理级别 |
|---------|---------|---------|
| 吸毒制毒 | 任何吸毒、制毒、贩毒场景的正面或中性描写 | 绝对禁止 |
| 赌博详细刻画 | 赌场、牌局的详细刻画 | 需判断 |
| 赌博反面教材 | 作为反面教材且模糊处理 | 允许 |

### 五、危险行为类

| 违规类型 | 具体表现 | 处理级别 |
|---------|---------|---------|
| 自杀自残 | 可能诱导观众模仿的自杀、自残行为 | 绝对禁止 |
| 危险驾驶 | 危险驾驶、极限作死的详细描写 | 需判断 |
| 公共安全 | 破坏公共设施、妨害交通的行为 | 需判断 |
| 教唆模仿 | 教唆他人进行危险行为 | 绝对禁止 |

### 六、其他违规类

| 违规类型 | 具体表现 | 处理级别 |
|---------|---------|---------|
| 未经授权 | 使用未经授权的品牌商标、名人肖像 | 绝对禁止 |
| 谣言虚假 | 传播谣言、虚假信息 | 绝对禁止 |
| 侮辱歧视 | 侮辱、诽谤、歧视特定群体（地域黑、性别歧视等） | 需判断 |

## 处理机制

### 绝对禁止词处理

当检测到绝对禁止词时：

1. **立即停止**该镜头组/内容的生成
2. **输出拒绝信息**，格式：
   ```
   ⚠️ 内容安全警告：当前剧本中包含绝对禁止内容——[具体违规描述]。
   请修改剧本后重新提交。无法处理涉及[违规类别]的内容。
   ```
3. **不输出**任何部分结果或半成品

### 需判断词处理

当检测到需判断词时：

1. **自动中性化处理**：使用同义词替换、添加修饰降低敏感度
2. **不中断**生成流程
3. **不添加**警告注释或说明
4. **直接输出**处理后的内容

**中性化原则**：
- 暴力描写 → 用暗示性语言替代直接描写
- 血腥细节 → 用环境反应替代（如"血滴"代替"血液喷涌"）
- 亲密场景 → 用情感表达替代身体描写
- 危险行为 → 弱化具体操作细节

### 与空镜Skill的协作机制

当暴力血腥内容在打斗场景中出现时：

1. **内容安全优先级高于空镜规则**
2. 空镜Skill的"文戏限定"规则被内容安全例外覆盖
3. 使用空镜做暗示性替代，常见手法：

| 原始内容 | 空镜替代方案 |
|---------|------------|
| 割喉血飙 | 墙上影子的剪影动作 + 血滴沿墙面滑落 |
| 剑刺胸口 | 剑尖滴血的特写 + 地面血滴扩散 |
| 重击头部 | 飞鸟惊起 + 弹壳/碎片落地 |
| 断肢场景 | 环境静默 + 风吹过空荡场景 |
| 死亡瞬间 | 道具反应（蜡烛熄灭/花瓶倾倒） |
| 大量伤亡 | 远景 + 战场烟雾弥漫（不展示细节） |

## 扫描流程

### 生成前预检

在规划阶段，对剧本原文执行：

```
步骤1：提取剧本原文
步骤2：逐句扫描，对照6大类违规标准
步骤3：标记违规点
  ├─ 绝对禁止词 → 停止，拒绝生成
  └─ 需判断词 → 记录位置，准备中性化
步骤4：通过预检，进入正常生成流程
```

### 生成后复核

在输出板块二前，对最终描述文本执行：

```
步骤1：提取板块二全部文本
步骤2：逐行扫描，对照6大类违规标准
步骤3：标记违规点
  ├─ 绝对禁止词 → 拒绝输出，提示用户修改
  └─ 需判断词 → 自动替换为中性化表达
步骤4：通过复核，输出最终内容
```

## 决策流程

面对任何内容生成，按以下顺序执行：

1. **生成前**：扫描剧本原文 → 绝对禁止词直接拒绝 → 需判断词记录位置
2. **生成中**：各Skill正常执行 → 需判断词在描述中自动中性化处理
3. **暴力场景特殊处理**：检测到过度血腥 → 触发空镜暗示替代机制
4. **生成后**：二次扫描板块二 → 确认无违规 → 输出

## 与其他 Skill 的协作

本技能是**全局守门员**，优先级最高：

```
P0: 内容安全 ← 最终审核层，不可被覆盖
P0: 时长约束（≤14秒）
P0: 音画匹配
P1: 镜头数范围 / 舒缓动态延续 / 组间衔接
P2: 空间连续性 / 流体剪辑 / 蒙太奇
P3: 运镜设计 / 色彩光影
```

与各Skill的具体协作：
- **空镜系统**：暴力血腥场景中，内容安全覆盖空镜的"文戏限定"规则，允许使用空镜暗示替代
- **武戏系统**：动作分解正常执行，但输出描述中的血腥细节被中性化
- **景别库/构图库/运镜大全/转场库**：正常调用，不受内容安全影响（除非描述含违规内容）
- **决策树系统**：正常调用，场景类型判定不受内容安全影响

## 输出要求

- 内容安全处理**对用户透明**（绝对禁止词除外）
- 需判断词的中性化处理**不添加任何注释**，用户看到的就是处理后的自然描述
- 仅绝对禁止词触发时才输出警告信息
