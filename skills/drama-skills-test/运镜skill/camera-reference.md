## 四、运镜组合策略详解

### 情绪升温组合
- 缓慢推近 + 聚焦转移 → 从环境聚焦到人物内心
- 呼吸式微晃 + 缓慢推近 → 亲密不安的窒息感
- 低角度跟拍 + 手持晃动 → 英雄的混乱与力量

### 情绪释放组合
- 缓慢拉远 + 升降 → 从个人抽离到全局，情绪释放
- 环绕 + 缓慢拉远 → 迷恋之后的清醒
- 快速拉远 + 广角变形 → 真相揭示的震惊

### 时空过渡组合
- 横摇 + 聚焦转移 → 连接两个时空/人物
- 急速甩镜 + 穿越运镜 → 时间跳跃/空间穿越
- 变焦拉远 + 升降 → 从微观到宏观的升华

### 紧张对抗组合
- 手持晃动 + 快速推拉 → 混乱战斗
- 低角度跟拍 + 景深压缩 → 追逐的窒息感
- 越轴 + 手持晃动 → 关系破裂的不安
