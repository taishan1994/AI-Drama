# 运镜大全 📷

运镜是镜头的"呼吸"。**本技能为每个镜头提供运镜方式的选择依据**，确保镜头运动精准服务于情绪和叙事。

## 核心规则

1. **每个镜头必须选择运镜方式**，不得使用"无运镜"或随意编造
2. **运镜描述必须包含视角+情绪意图+运动细节**
   - ❌ "缓慢推近"
   - ✅ "平视缓慢推近，从环境聚焦到人物面部，制造亲密感"
3. **每个镜头只用1种运镜**（可叠加1个焦点控制），避免运镜堆砌
   - ❌ "推镜+环绕+横移"
   - ✅ "缓慢推近"
4. **运镜选择必须有明确的情绪理由**，不是随机分配
5. **空镜运镜优先使用缓慢横摇、升降、聚焦转移**，避免快速运镜破坏宁静感

## ⚠️ 与其他 Skill 的优先级

**运镜在景别和构图确定之后选择。**

执行顺序：景别库 → 构图库 → **运镜库** → 空镜系统（按需）

运镜不得改变景别和构图的既定选择，只能在既定画面内运动。例如：
- 景别选了"中景"→ 运镜不能推到"特写"范围（否则应由景别库决定）
- 构图选了"三分法"→ 运镜保持三分法布局内运动

**例外**：景别库的"节奏变化"（如远景→特写）可以在一个镜头内通过运镜实现推近效果，但需在描述中明确标注起始景别和结束景别。

## 运镜选择决策流程

面对任何镜头，**按以下顺序回答5个问题**，从运镜库中选择最匹配的运镜方式：

### 问题一：这个镜头的情绪任务是什么？

| 情绪 | 推荐运镜 |
|------|---------|
| 紧张、紧迫 | 手持晃动、快速推拉、快速横移 |
| 温暖、亲密 | 缓慢推近、呼吸式微晃、环绕 |
| 震撼、宏大 | 升降、缓慢拉远、航拍 |
| 宁静、平静 | 缓慢横移、慢摇、缓慢拉远 |
| 不安、悬疑 | 呼吸式微晃、缓慢推近、聚焦转移 |
| 孤独、疏离 | 缓慢拉远、升降、鸟瞰 |
| 激动、爆发 | 快速推近、甩镜头、手持晃动 |

### 问题二：这个镜头的叙事功能是什么？

| 功能 | 推荐运镜 |
|------|---------|
| 推进剧情 | 中速推近、跟随摇 |
| 揭示信息 | 揭示摇、聚焦转移、快速拉远 |
| 情绪渲染 | 缓慢推近、环绕、呼吸式微晃 |
| 空间展示 | 慢摇、横移、升降 |
| 时间过渡 | 慢摇、升降、延时摄影 |

### 问题三：观众此刻的注意力应该在哪里？

| 注意力目标 | 推荐运镜 |
|-----------|---------|
| 人物面部 | 缓慢推近、变焦推进 |
| 动作细节 | 快速推近、跟随跟拍 |
| 环境 | 慢摇、横移、升降、拉远 |
| 道具 | 聚焦转移、缓慢推近 |
| 人物关系 | 环绕、过肩镜头、横移 |

### 问题四：从运镜库中选择最匹配的运镜

综合以上三个问题，选择运镜。若有多个候选，选与上一镜头运镜差异较大的那个（制造节奏变化）。

### 问题五：运镜输出格式

输出格式：`[视角]，[运镜类型]+[跟随/对准的主体及运动方向]+[情绪意图]`

示例：
- "平视缓慢推近焦点从环境移至面部，制造亲密感"
- "贴地手持晃动跟拍林风奔跑，制造紧迫感"
- "鸟瞰缓慢拉远，从个人抽离到全局，情绪释放"

## 运镜组合策略

当单个运镜不足以表达复杂情绪时，可参考以下组合策略（在镜头组层面应用，非单镜头叠加）：

| 组合类型 | 运镜组合 | 效果 |
|---------|---------|------|
| 情绪升温 | 缓慢推近 → 聚焦转移 | 从环境聚焦到人物内心 |
| 情绪升温 | 呼吸式微晃 + 缓慢推近 | 亲密不安的窒息感 |
| 情绪释放 | 缓慢拉远 + 升降 | 从个人抽离到全局 |
| 情绪释放 | 快速拉远 + 广角变形 | 真相揭示的震惊 |
| 时空过渡 | 横摇 + 聚焦转移 | 连接两个时空/人物 |
| 紧张对抗 | 手持晃动 + 快速推拉 | 混乱战斗 |
