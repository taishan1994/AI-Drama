## 使用指南

### 选择流程

1. **确定情绪方向**：本组镜头的核心情绪是什么？
2. **选择空镜类型**：需要交代时空（写景）还是传递情绪（写物）？
3. **匹配场景环境**：素材是否与当前场景的光影、色调、季节一致？
4. **确定衔接方式**：空镜与前后镜头的关联是什么？（音桥/图形匹配/动势延续/因果暗示/情绪转喻）

### 改编原则

- 素材可直接使用，也可根据场景改编（如"雨滴沿窗滑落"→"雨滴沿帐篷滑落"）
- 改编时保持核心意象不变，仅调整环境细节
- 确保改编后的素材与当前场景的光影、色调一致
