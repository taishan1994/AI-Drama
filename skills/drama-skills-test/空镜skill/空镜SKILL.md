# 空镜系统 🌿

空镜是角色不以"正脸全身"直接出现的镜头，分为**写景**和**写物**两大类。写景交代时空，写物传递情绪。**本技能仅适用于文戏场景**。

## ⚠️ 核心规则：空镜仅限文戏场景

**空镜大量使用仅限于文戏场景**（对话、情感、内心戏、对峙、氛围渲染等非动作场景）。

**文戏场景明确包含以下类型**：
- 对话场景（两人或多人交谈）
- 情感场景（哭泣、崩溃、独白、离别、重逢）
- **对峙场景（人物僵持、关系张力、沉默对视）** ← 此类场景空镜效果尤为突出
- 氛围场景（环境渲染、意境营造）
- 内心戏（回忆、幻想、心理活动）

**非文戏场景（动作、打斗、追逐、爆炸等）禁止大量使用空镜**，仅在以下特殊情况下可少量使用：
- 场景转换需要（如从室内切到室外）
- 明确的剧情转场点（如时间跳跃）
- 导演明确要求的特殊效果
- **内容安全需要**：当直接展示某个动作会触发内容安全违规时，使用空镜替代直接展示。**内容安全优先于空镜限制规则。**

### 内容安全空镜替代方案

当需要暗示暴力/血腥但不能直接展示时：

| 想表达的内容 | 空镜替代 | 示例 |
|------------|---------|------|
| 角色被割喉 | 墙上影子的动作 | 月光下，墙上映出刀刃划过的影子 |
| 角色被刺杀 | 血滴/血迹 | 一滴血落在地面枯叶上，缓缓晕开 |
| 角色中枪 | 枪口烟雾/弹壳 | 弹壳落地，在石板上弹跳旋转 |
| 角色倒地死亡 | 环境静默 | 风吹过空旷的战场，旗帜缓缓飘落 |
| 角色被殴打 | 道具反应 | 沙袋剧烈摇晃，灰尘在光束中飞舞 |
| 大规模杀戮 | 远景空镜 | 夕阳下，乌鸦盘旋在废弃战场上方 |

**核心原则**：暴力行为"发生"在画外，空镜只展示"结果"或"暗示"，让观众脑补而非直接看到。

## 一、写景镜头（全景/远景，交代时空）

让观众知道"这是什么地方、什么时间、什么氛围"。

| 子类 | 示例 | 推荐运镜 |
|------|------|---------|
| 城市俯瞰 | 十字路口车流如血液流动、写字楼窗户逐格亮灭、高架桥车灯拉成光带 | 鸟瞰缓慢升降/航拍横移 |
| 人群俯瞰 | 广场人流如蚁、地铁口人潮涌出、夜市鸟瞰成光斑 | 鸟瞰固定或缓慢推近 |
| 自然远景 | 远山+炊烟、云海翻涌、河流蜿蜒穿过大地、沙漠驼队 | 缓慢横摇/升降 |
| 街道全景 | 雨后空旷街道、黄昏巷弄、霓虹灯亮起的夜景 | 中速横移/缓慢拉远 |
| 时间过渡 | 日出→日落延时、季节变化、晴天→暴雨 | 缓慢叠化/延时 |

## 二、写物镜头（近景/特写，暗示情绪）

不直接告诉观众"角色在想什么"，而是让观众自己感受到。

| 子类 | 示例 | 推荐运镜 |
|------|------|---------|
| **角色局部** | 手握方向盘、脚踩油门、手指悬在键盘上、握剑指关节发白 | 缓慢推近/呼吸式微晃 |
| **角色映射** | 水坑倒影、车窗映像、墨镜中映出对面人脸、电梯门关前的映像 | 缓慢横移/聚焦转移 |
| **角色痕迹** | 雪地脚印、刚推开的椅子、还在冒烟的烟、浴室镜子水雾擦痕 | 缓慢拉远/固定镜头 |
| **缝隙窥视** | 门缝中的眼睛、窗帘缝隙侧脸、百叶窗条纹光影下的手 | 固定镜头/极慢推近 |
| **动态静物** | 风铃被风吹动、晾衣绳衣物在夕阳中飘、旗帜翻卷、窗帘被风鼓起 | 缓慢横摇/呼吸式微晃 |
| **光影静物** | 蜡烛摇曳、丁达尔光穿过树叶、水面光斑在天花板晃动 | 固定/极缓慢推近 |
| **自然静物** | 花瓣飘落、露珠从叶尖滑落、枯叶在水面旋转、蜻蜓停在叶尖 | 缓慢推近/聚焦转移 |
| **人文静物** | 红灯笼、经幡、茶具、旧照片、风铃、信封蜡封 | 缓慢横摇/升降 |
| **声音静物** | 钟摆滴答、雨打芭蕉、远处蝉鸣（画面只有物件） | 固定镜头 |
| **感官空镜** | 触觉：手指抚摸旧照片边缘、赤脚踩在冰凉石板上；嗅觉：厨房飘出的热气、花丛中蜜蜂环绕；味觉：咬柠檬时眉头微皱、热汤入口时眼睛微眯 | 缓慢推近/特写固定 |

**写物优先于写景**——越贴近角色越有叙事力。

## 三、空镜情绪速查

| 情绪 | 写景推荐 | 写物推荐 |
|------|---------|---------|
| 平静/宁静 | 月光庭院、湖面涟漪 | 茶杯热气、风铃、窗帘微风 |
| 忧伤/孤独 | 雨后空街、黄昏巷弄 | 空荡秋千、雨滴滑落、枯叶飘落 |
| 紧张/不安 | 乌云遮月、光线忽明忽暗 | 影子拉长、门缝光线、钟表滴答 |
| 希望/新生 | 晨光穿云、天际鱼肚白 | 嫩芽破土、冰面裂缝、花瓣飘落 |
| 震撼/宏大 | 闪电劈裂山谷、瀑布倾泻 | 碎玻璃飞溅、火焰吞噬 |
| 愤怒/狂暴 | 乌云翻滚压顶 | 火舌扭动、地面裂缝扩展 |
| 心动/甜蜜 | 夕阳金边云层 | 阳光移动、指尖靠近、气泡彩虹 |
| 温暖/亲密 | 炊烟远山、黄昏街道 | 炉火噼啪、烛光摇曳、热气升腾 |

## 四、空镜衔接技巧（强制）

空镜必须与前后镜头有明确的衔接关系，使用以下技巧之一：

1. **音桥衔接**：上一镜角色说"走吧"→空镜（城市街景）→下一镜角色出现在新场景，对话声延续到空镜中
2. **图形匹配**：上一镜角色眼睛特写→空镜（圆形月亮/圆形车轮），形状呼应
3. **动势延续**：上一镜角色向右走→空镜（窗帘被风向右吹），方向一致
4. **因果暗示**：上一镜角色关窗→空镜（窗外雨滴打在玻璃上），动作与结果
5. **情绪转喻**：上一镜角色愤怒→空镜（火焰吞噬枯枝），情绪外化

## 五、文戏场景空镜使用规则

### 对峙场景专用指导

- 对峙场景的空镜核心功能是**制造沉默中的张力**，不是填充时间
- **频率**：每1-2个对峙镜头可插入1个空镜（高于普通对话）
- **推荐类型**：环境渲染（压抑氛围）+ 隐喻象征（暗示关系/命运）+ 情绪缓冲（眼神交锋间喘息）
- **推荐素材**：烛火摇曳、时钟滴答、窗帘微动、影子拉长、冷风吹过、雨声渐起
- **推荐运镜**：缓慢推近（压迫感递增）、呼吸式微晃（紧张不安）、聚焦转移（注意力在角色与环境间切换）
- 空镜应与对峙双方的空间关系呼应（如两人之间有什么？窗外有什么？空气中有何变化？）

### 普通对话/情感场景

- 每2-3个对话镜头可插入1个空镜
- 情感高潮前后必须有空镜缓冲
- 内心戏可用空镜外化角色心理状态
- 沉默时刻优先用空镜填充而非让画面静止

### 非文戏场景限制

- **禁止大量使用空镜**
- 仅在场景转换、剧情转场点、导演明确要求时可使用
- 空镜数量不超过总镜头数的10%

## 六、空镜选择决策流程

### 第一步：判断场景类型

| 场景类型 | 判断标准 | 空镜策略 |
|----------|---------|---------|
| **文戏** | 对话、情感、内心戏、对峙、氛围 | ✅ 大量使用 |
| **动作** | 打斗、追逐、爆炸、激烈运动 | ❌ 禁止大量使用 |
| **混合** | 同时包含文戏和动作 | ⚠️ 仅文戏部分使用 |

### 第二步：选择空镜类型

问自己：这组镜头需要交代时空，还是传递情绪？

- 需要让观众知道"在哪、什么时候" → **写景**
- 需要让观众感受到"角色的情绪" → **写物**（优先）
- 需要让观众"呼吸一下" → **静物空镜**（写物子类）

### 第三步：选择具体素材

参考【情绪速查表】选择对应情绪的写景/写物素材。

### 第四步：确定衔接方式

参考【衔接技巧】确保空镜与前后镜头有视觉/情绪关联。

## 七、空镜运镜指导

| 运镜类型 | 适用场景 | 情绪效果 |
|---------|---------|---------|
| 缓慢横移 | 展示环境全貌 | 优雅、平静、沉浸 |
| 升降镜头 | 从细节到全局或反之 | 宏大、超脱、俯瞰/仰视 |
| 聚焦转移 | 从前景到后景或反之 | 揭示、注意转移 |
| 呼吸式微晃 | 近距离空镜特写 | 亲密、脆弱、生命力 |
| 慢速推近 | 聚焦关键道具/景象 | 渐进情感投入、悬念递增 |
| 缓慢拉远 | 从细节扩展到环境 | 开阔、沉思、疏离 |

**避免使用**：快速推拉、甩镜头、手持晃动等激烈运镜。

## 八、空镜输出格式

空镜使用与角色镜头相同的格式：

```
【镜头X】
转场: [转场类型]
[景别]+[构图]+([空镜元素])+[核心动作描述]+[场景细节]+[运镜方式]+[光影效果]
音效: [音效描述]
```

**示例**：
```
【镜头3】（空镜·写物·动态静物）
转场: 叠化
特写+留白+(风铃)+被微风吹动纸条翻飞发出清脆声响+檐下木柱斑驳+平视呼吸式微晃+暖色调午后阳光
音效: 风铃叮当声，远处蝉鸣
```
