# 构图库 🎨

构图是画面的骨架。**本技能为每个镜头提供构图和景深的选择依据**，确保画面空间布局精准服务于情绪和叙事。

## 核心规则

1. **每个镜头必须选择构图方式**，不得随意摆放画面元素
2. **构图意图融入场景细节描述**，不单独标注构图名称
   - ❌ "采用三分法构图，主角位于右上交点"
   - ✅ "女主角偏居画面右侧三分之二处，左侧留出大片被月光照亮的空旷庭院"
3. **景深与构图配合使用**，景深决定画面焦点范围，构图决定元素位置
4. **构图服务于情绪**：稳定→对称/三分法；紧张→对角线/引导线；孤独→留白

## ⚠️ 与其他 Skill 的优先级

**当构图选择与景别选择冲突时，景别优先，构图向景别让步。**

| 冲突场景 | 景别选择 | 构图调整 |
|---------|---------|---------|
| 大特写 + 留白 | 大特写画面被填满，无法留白 | 构图改为**选择性聚焦**或**三分法** |
| 远景 + 三分法 | 远景展示全局，主体远离 | 三分法交叉点放人物位置 ✅ 无冲突 |
| 特写 + 框架 | 特写范围小，框架难以形成 | 构图改为**选择性聚焦**或**浅景深** |

**原则**：景别决定"看到多少"，构图决定"怎么安排"。景别是第一优先级，构图在景别确定后选择适配方案。

## 构图选择决策流程

面对任何镜头，**按以下顺序回答5个问题**，从构图库中选择最匹配的构图方式：

### 问题一：主体与环境的关系是什么？

| 关系 | 推荐构图 | 推荐景深 |
|------|---------|---------|
| 主体突出，环境退后 | 三分法 / 留白 | 浅景深（背景虚化） |
| 主体与环境同等重要 | 引导线 / 框架 | 中景深（前中景清晰，背景适度虚化） |
| 环境压过主体 | 对称 / 放射线 | 深景深（前景到背景全部清晰） |

### 问题二：需要什么样的情绪节奏？

| 情绪 | 推荐构图 |
|------|---------|
| 稳定、平静 | 对称 / 三分法 / 三角形 |
| 动感、紧张 | 对角线 / 引导线 |
| 孤独、沉思 | 留白 / 黄金分割 |
| 窥视、聚焦 | 框架 / 选择性聚焦 |
| 和谐、高级感 | 黄金分割 |

### 问题三：场景类型适配

| 场景 | 推荐组合 |
|------|---------|
| 宫殿 / 仪式 | 对称 + 浅景深 |
| 打斗 / 追逐 | 对角线 + 动态景深 |
| 风景 / 环境建立 | 引导线 + 深景深 |
| 人物情感 | 三分法 / 黄金分割 + 浅景深 |
| 夜景 / 灯光场景 | 散景效果 |

### 问题四：画幅适配

- **9:16 竖屏**：引导线纵向延伸，留白上下分布，避免横向一字排开
- **16:9 横屏**：引导线横向延伸，对称左右分布，利用左右空间展开

### 问题五：将构图意图融入画面描述

不单独标注构图名称，在场景细节中自然体现。例如：
- 留白 → "左侧大片被月光照亮的空旷庭院"
- 框架 → "前景虚化的门框形成画框，将主角框在其中"
- 对角线 → "两人沿画面对角线对峙，制造张力"
