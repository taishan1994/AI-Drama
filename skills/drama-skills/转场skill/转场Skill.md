# 转场库 🎬

转场是连接镜头组与镜头组、段落与段落之间的桥梁。**本技能为镜头组之间的衔接提供转场方式的选择依据**。

## 核心规则

1. **默认硬切**：除非有明确的叙事意图，否则不使用特殊转场，直接硬切
2. **转场服务于叙事**，不是装饰——每个特殊转场必须有明确的情绪或叙事理由
3. **同组内不使用转场**：转场只存在于镜头组与组之间，组内镜头之间默认硬切
4. **转场类型与场景风格匹配**：古风→水墨转场；赛博朋克→霓虹闪烁；仙侠→烟雾转场

## ⚠️ 与其他 Skill 的关系

转场是**组间衔接工具**，作用于镜头组与组之间，不影响组内镜头的景别/构图/运镜选择。

执行顺序：空镜系统 → 景别库 → 构图库 → 运镜库（组内）→ **转场库**（组间）

## 转场选择决策流程

面对任何两个镜头组之间的衔接，**按以下顺序回答6个问题**：

### 第一步：默认硬切

除非以下步骤给出明确理由，否则不使用特殊转场。

### 第二步：是否需要时间标记？

| 时间关系 | 推荐转场 |
|---------|---------|
| 明显时间跳跃（数小时/天/年） | 淡入淡出 / 黑屏 / 叠化 |
| 短暂时间流逝（数分钟） | 叠化 / 慢速叠化 |
| 回忆闪现 | 交叉叠化 / 慢速叠化 |
| 快速时间压缩 | 时间跳切 |

### 第三步：是否需要空间过渡？

| 空间关系 | 推荐转场 |
|---------|---------|
| 不同场景，需要流畅连接 | 匹配剪辑（形状/动作/视线）/ 遮挡转场 |
| 不同场景，需要强烈分隔 | 黑屏 / 甩镜头 |
| 同一场景，视角切换 | 遮挡转场 / 视线匹配 |

### 第四步：情绪是否需要过渡？

| 情绪变化 | 推荐转场 |
|---------|---------|
| 情绪剧烈变化 | 黑屏 / 甩镜头 |
| 情绪延续或渐变 | 叠化 / 声桥 |
| 情绪跳跃（震惊） | 甩镜头 / 双甩镜头 |
| 温柔过渡 | 慢速叠化 / 交叉叠化 |

### 第五步：场景风格适配

| 风格 | 推荐转场 |
|------|---------|
| 古风/国风 | 水墨转场 |
| 仙侠/玄幻 | 烟雾转场 |
| 赛博朋克/都市 | 霓虹闪烁 |
| 温馨/回忆 | 光效转场 |

### 第六步：转场输出格式

在板块二的 `转场:` 字段中填写选中的转场类型。无特殊转场时填"无"（即硬切）。

## 转场与音效的配合

- **J转场（声音先行）**：下一个场景的声音先于画面出现，制造悬念和铺垫
- **L转场（声音延续）**：当前场景的声音滞后于画面消失，制造余韵和连接
- **声音桥接**：环境声跨场景延续，保持听觉连贯性
