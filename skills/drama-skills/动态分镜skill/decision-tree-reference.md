# 动态分镜决策树 — 详细参考手册

## 一、场景类型判定细则

### 动作场景判定标准

**明确动作场景**：
- 包含拳脚交锋、兵器格斗
- 追逐、逃跑（有紧迫感）
- 爆炸、坍塌等物理冲击
- 高速运动（飙车、滑翔、飞行战斗）

**边界情况**：
- 对峙：不算动作场景，算情绪场景（关系张力）或对话场景
- 争吵+推搡：主导类型为对话（情绪交锋），仅在推搡升级为打斗时转为动作场景
- 轻微肢体语言（握手、拥抱、挥手）：不算动作场景

### 情绪场景判定标准

**明确情绪场景**：
- 角色内心独白、回忆闪现
- 情感爆发（哭泣、崩溃、狂喜）
- 关系对峙（双方对视，气氛紧张）
- 离别、重逢、告白等情感高潮

**边界情况**：
- 含少量台词的情绪爆发：主导类型仍为情绪，对话融入情绪框架
- 无台词的情绪场景：纯情绪渲染，空镜Skill大量参与

### 对话场景判定标准

**明确对话场景**：
- 两人及以上持续对话
- 信息传递、解释、讨论
- 争论、吵架

**边界情况**：
- 对话中突然情绪爆发：在爆发点切换为情绪场景路径
- 对话中爆发打斗：在打斗点切换为动作场景路径

### 氛围/意境场景判定标准

**明确氛围场景**：
- 纯环境描写（风景、城市、天气变化）
- 空镜组（无角色出现）
- 意境镜头（诗化表达、留白、隐喻）

**边界情况**：
- 角色在环境中行走但无对话/动作：仍为氛围场景
- 环境中有微弱肢体语言（角色望向远方）：氛围为主导

### 蒙太奇场景判定标准

**触发条件（满足任意一项）**：
- 剧本明确要求"同时"、"另一边"、"与此同时"等并行线索
- 需要用自然/物体画面隐喻人物内心状态
- 需要多个相似画面快速堆叠强化某种情绪
- 配合音乐/节拍进行视觉化剪辑
- 需要通过相似形状/运动/色彩建立视觉联想

**不触发的情况**：
- 线索单一，无并行叙事需求
- 镜头时长不够支撑蒙太奇结构（总时长<6秒不建议用蒙太奇）
- 蒙太奇会导致总时长超14秒且无法压缩

## 二、各决策树详细规则

### 动作场景 — 路径A（冲击力优先）

**镜头时长分配**：
- 蓄力/起势镜头：1-1.5秒
- 交锋/高潮镜头：1-2秒
- 结果/位移镜头：1-1.5秒
- 呼吸帧：0.5-1秒

**剪辑节奏**：
- 快速短切，每1-2秒切换一次
- 在打击点切镜（动作切点优化）
- 通过越轴/不规则角度制造混乱感

**运镜选择**：
- 手持晃动（混乱感）
- 快速推拉（冲击力）
- 低角度跟拍（速度感）
- 急速甩镜（转场/打击瞬间）

**景别节奏**：
- 特写（打击点）→ 远景（位移）→ 特写（反击）→ 全景（环境）
- 快速切换，制造紧张感

### 动作场景 — 路径B（力量感与真实性）

**动作分解时长**：
- 起始：1-1.5秒（蓄力过程需可见）
- 发力：0.5-1秒（爆发瞬间）
- 接触：0.5秒（定格/慢镜头强化）
- 受力：0.5-1秒（受击者反应）
- 结束：0.5-1秒（收势/调整）

**生理细节要求**：
- 攻击者：肌肉紧绷、青筋暴起、咬紧牙关、呼吸急促
- 受击者：表情痛苦、身体弯曲、护痛动作、踉跄
- 双方：汗水飞溅、衣料撕裂、脚下扬尘

**物理逻辑检查**：
- 出拳 → 必须转腰带动
- 踢腿 → 必须有支撑脚
- 跳跃 → 必须有起跳蓄力和落地缓冲
- 投掷 → 手臂后摆蓄力再释放

### 情绪场景 — 路径A（内心戏/情感爆发）

**景别推进**：
- 开始：近景（建立角色状态）
- 发展：特写（聚焦面部）
- 高潮：大特写（瞳孔/嘴唇/泪珠）
- 释放：远景/空镜（情绪释放/缓冲）

**运镜节奏**：
- 缓慢推近（情绪升温）
- 环绕（内心挣扎/多角度审视）
- 焦点转移（注意转移/潜台词）
- 呼吸式微晃（亲密感/脆弱感）

**光影辅助**：
- 半边脸阴影 → 内心挣扎
- 眼神光 → 生命力/希望
- 背光剪影 → 神秘/未知
- 顶光 → 审判/压力

**音效策略**：
- 高潮前：留白（静默是最强音效）
- 高潮中：心跳声/呼吸声渐强
- 高潮后：环境声恢复/音乐渐入

### 情绪场景 — 路径B（关系张力/对峙）

**空间关系**：
- 距离近 → 亲密/压迫
- 距离远 → 疏离/对峙
- 中间有遮挡 → 隔阂/试探

**镜头手法**：
- 过肩镜头 → 制造对话双方的压迫感
- 越轴 → 制造不安/关系紧张
- 正反打 → 标准对话/信息传递
- 双人中景 → 关系展示

**运镜策略**：
- 缓慢横移 → 揭示环境与人物关系
- 推近 → 拉近亲密距离
- 拉远 → 制造疏离感
- 越轴横移 → 关系破裂感

### 对话场景 — 路径A（信息传递）

**正反打规则**：
- 说话者：近景/中景，轻微推近
- 倾听者：中景，轻微拉远或保持
- 重要台词：说话者切换为特写
- 过渡台词：保持中景

**辅助镜头**：
- 道具特写：转移注意力/强调关键信息
- 环境细节：交代场景/调节节奏
- 反应镜头：倾听者微表情

**对话节奏**：
- 快速对话：短镜头交替（1-1.5秒）
- 正常对话：中等镜头（2-3秒）
- 沉思对话：长镜头（3-4秒）+ 沉默留白

### 对话场景 — 路径B（情绪交锋/争吵）

**镜头距离推进**：
- 开始：中景（标准对话距离）
- 升温：近景（拉近亲密距离）
- 激烈：特写（面部微表情放大）
- 爆发：大特写（嘴唇/眼睛特写）

**越轴策略**：
- 在情绪升温点执行越轴（制造不安）
- 越轴后镜头距离缩短（压迫感增强）
- 越轴角度逐渐加大（紧张感递增）

**打断与沉默**：
- 抢话时：快速推近说话者
- 打断时：甩镜头切换
- 沉默时：长镜头+呼吸式微晃+环境声突显

### 氛围/意境场景 — 路径A（环境渲染）

**镜头时长**：
- 环境建立镜头：3-5秒（让观众沉浸）
- 氛围过渡镜头：2-3秒
- 空镜组：每个1-2秒

**运镜选择**：
- 缓慢横摇（展示环境全貌）
- 升降（从个人到全局/从宏观到微观）
- 航拍（鸟瞰全局）
- 穿越运镜（进入空间/探索环境）

**光影变化**：
- 日出 → 金色暖光，长阴影
- 日落 → 橙红色调，渐暗
- 阴天 → 柔光，低对比度
- 夜晚 → 月光/灯光，高对比度

### 氛围/意境场景 — 路径B（隐喻镜头）

**隐喻手法**：
- 直接隐喻：人物状态 ↔ 自然现象（如人物崩溃 ↔ 暴风雨）
- 间接隐喻：道具/细节暗示（如枯萎的花 = 关系死亡）
- 环境隐喻：场景氛围暗示人物内心（如阴暗走廊 = 内心黑暗）

**运镜选择**：
- 缓慢推进 → 引导注意力至隐喻物
- 焦点转移 → 从人物到隐喻物（或反之）
- 叠印/叠化 → 人物与隐喻物交融

### 蒙太奇 — 5种类型详解

**隐喻蒙太奇**：
- 结构：A镜头（人物状态）+ B镜头（自然/物体）= 新含义
- 视觉关联：A和B必须有颜色、形状、运动或情绪上的关联
- 时长分配：1:1（均衡）或 2:1（以人物为主）
- 转场：叠化（1-2秒重叠）
- 示例：A(女主角流泪) + B(雨滴滑落玻璃) = 悲伤如雨

**平行蒙太奇**：
- 结构：ABAB交替剪辑，逐步缩短镜头长度
- 交替次数：3-5次
- 时长规律：A1(2s) → B1(2s) → A2(1.5s) → B2(1.5s) → A3(1s) → B3(1s)
- 转场：硬切（节奏感）或J转场（声音先行暗示切换）
- 音效：两条线索各自主导，切换时交替
- 示例：A(主角奔跑) + B(反派等待) = 追逐的紧张感

**积累蒙太奇**：
- 结构：多个相似镜头快速堆叠，时长递减
- 时长分配：2s → 1.5s → 1s → 0.5s，最后一镜延长至2-3s释放
- 镜头数：4-8个
- 转场：硬切（快速短切）
- 音效：逐镜递增（如心跳声渐强）
- 示例：多个紧张面部特写快速堆叠 → 最后一镜定格（情绪爆发）

**节奏蒙太奇**：
- 结构：根据音乐或心跳节奏剪辑
- 时长：与BPM匹配（如120BPM → 每0.5秒切一次）
- 关键点：动作点必须在重拍上
- 转场：硬切（严格同步）
- 音效：音画严格同步
- 示例：鼓点声中，每个重拍切一个动作镜头

**联想蒙太奇**：
- 结构：相似形状/运动/色彩的镜头串联
- 转场：叠化或形状匹配剪辑
- 运镜：各镜头采用相似运动轨迹
- 环境音：跨镜头渐变（如水声→雨声→掌声）
- 示例：A(手翻书页) → B(扇子展开) → C(蝴蝶展翅) = "展开/飞翔"联想

## 三、流体剪辑技巧详解

### 动势延续

**操作方式**：
- 上一镜头结尾有明确运动方向（如角色向右挥拳）
- 下一镜头起始延续该动势（如下一镜头从右侧切入，物体被拳风带动）

**适用场景**：
- 所有场景类型
- 特别适合动作场景的连续性

**注意事项**：
- 运动方向必须一致或自然过渡
- 速度可变化（如快拳后慢镜头收势）

### 图形匹配

**操作方式**：
- 不同场景通过相似形状、色彩、构图实现视觉流动
- 上一镜头的圆形物体 → 下一镜头的圆形物体
- 上一镜头的对角线构图 → 下一镜头的对角线构图

**适用场景**：
- 转场衔接
- 蒙太奇（联想蒙太奇）
- 场景跳转时保持视觉连贯性

### 视线引导

**操作方式**：
- 人物视线方向与下一镜头主体位置匹配
- 角色向左看 → 下一镜头主体在画面左侧
- 角色向上看 → 下一镜头为仰视角度

**适用场景**：
- 对话场景（正反打）
- 情绪场景（人物望向某处→揭示所望内容）
- 氛围场景（人物望向窗外→窗外景色）

### 动作切点优化

**操作方式**：
- 在动作的高潮点或转折点切换镜头
- 出拳的最高点 → 切换到受击者反应
- 关门的瞬间 → 切换到门外场景

**适用场景**：
- 动作场景（最常用）
- 对话场景（打断/抢话的切换点）
- 转场衔接（利用动作遮挡）

## 四、镜头编排结构详解

单个镜头拍得好不够，镜头之间的排列顺序决定了故事怎么讲。以下5种编排结构根据剧本情绪自动选用。

### 悬念三段式：结果→过程→揭晓

**核心逻辑**：打破时间顺序，通过"结果先行→关键过程→揭示原因"引导观众主动思考。

**编排步骤**：
1. **钩子镜头（结果先行）**：只展示事件的结果或冲突点，不交代原因。如：破碎的玻璃、滴落的血迹、人物惊恐的表情。作用：瞬间抓住注意力，激发好奇心。
2. **过程镜头（关键动作）**：展示事件发展中的关键动作，但不给出全貌。如：凶手擦拭指纹的手部特写、主角急促奔跑的脚步。作用：通过局部细节暗示进展，保持悬念。
3. **释放镜头（揭示答案）**：揭示事件的原因、情绪或反转。如：凶手转身露出正脸、主角发现线索后的崩溃表情。作用：满足好奇心，传递情感冲击。

**节奏**：短→短→长（钩子1s、过程1-2s、释放2-3s）

**示例**：
- 钩子：黑暗中玻璃碎裂声，画面只拍一地碎玻璃
- 过程：戴手套的手捡起玻璃碎片，镜头跟随手部动作
- 释放：手部主人转身，露出主角惊恐的脸——原来他才是"受害者"

### 递进式：远→中→近→特写

**核心逻辑**：通过景别逐镜收窄，制造"越来越近"的压迫感或亲密感。

**编排步骤**：
1. 远景/全景：建立环境，交代空间
2. 中景：展示人物与环境的关系
3. 近景：聚焦人物上半身，开始传递情绪
4. 特写/大特写：放大面部细节或关键道具

**节奏**：每镜时长可递减（如3s→2s→1.5s→1s），运镜逐镜加速。

### 反差式：美好→破坏→余韵

**核心逻辑**：用前后两段的极端对比制造情感冲击。

**编排步骤**：
1. **美好段**：暖色调、平稳运镜、柔和光影，建立"一切安好"的假象
2. **转折点**：硬切/甩镜/黑屏，打断美好
3. **破坏段**：冷色调、手持晃动、高对比光影，展示失去
4. **余韵段**：缓慢拉远/空镜，给观众消化时间

**关键**：两段情绪越极端，冲击越大。

### 循环式：开头=结尾，含义变了

**核心逻辑**：首尾镜头完全一致，但观众在看完故事后对同一画面的理解完全不同。

**编排步骤**：
1. 开场镜头：特定构图/景别/运镜的画面
2. 中间内容：讲述故事
3. 结尾镜头：与开场完全一致的构图/景别/运镜，但角色表情/姿态/光影发生变化

**效果**：观众自行对比首尾差异，感受角色的成长/改变/领悟。

### 碎片式：多个短镜头快速拼接

**核心逻辑**：通过无规律的短镜头堆叠，制造混乱、回忆闪回或时间流逝感。

**编排要点**：
- 每镜≤1秒
- 景别/角度随机跳跃
- 运镜以手持晃动+甩镜为主
- 音效叠加或静音

**与积累蒙太奇的区别**：
- 碎片式 = "混乱的叙事"，镜头无规律，讲的是"事情很乱"
- 积累蒙太奇 = "强度的堆叠"，镜头相似且时长递减，讲的是"情绪在累积"

## 五、场景类型快速判定表

| 剧本关键词 | 场景类型 | 决策路径 |
|-----------|---------|---------|
| 打斗/格斗/出拳/踢/兵器 | 动作 | 路径A或B |
| 追逐/逃跑/飙车/追赶 | 动作 | 路径A |
| 哭/笑/崩溃/狂喜/独白 | 情绪 | 路径A |
| 对峙/对视/僵持/试探 | 情绪 | 路径B |
| 说/问/答/聊/讨论/争论 | 对话 | 路径A或B |
| 风景/夜空/雨/雪/空旷 | 氛围 | 路径A |
| 象征/隐喻/如/仿佛/像 | 氛围 | 路径B |
| 同时/另一边/与此同时 | 蒙太奇 | 平行 |
| 快速/交替/堆叠/节奏 | 蒙太奇 | 积累/节奏 |

## 六、场景切换处理规则

当一个镜头组内发生场景类型切换时：

| 切换 | 处理方式 |
|------|---------|
| 对话→打斗 | 在切换点使用越轴或快速推镜，标记类型转变 |
| 打斗→对话 | 在呼吸帧中引入对话，自然过渡 |
| 情绪→打斗 | 情绪爆发点触发动作，用快速切镜标记转变 |
| 打斗→情绪 | 最后一击用慢镜头，收势中融入情绪表达 |
| 任何→氛围 | 用缓慢拉远或升降脱离当前场景，进入环境渲染 |
