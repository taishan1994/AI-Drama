## 三、协同校验规则详解

### 逻辑一致性

- 攻击后必须有防守反应或位移，禁止敌人静止挨打
- 连续攻击时，每次攻击之间有蓄力/调整动作
- 角色受伤后应有对应的行动受限表现（跛行、护痛、动作减缓）
- 多人混战时，明确每个角色的目标和状态

### 道具连续性

- 武器在镜头切换时保持位置一致（除非有明确的传递/丢弃动作）
- 手持物品在正反打中方向一致
- 损坏的道具在后续镜头中保持损坏状态
- 投掷物的飞行轨迹符合物理规律

### 视线连续性

- 攻击者视线锁定目标方向
- 防御者视线跟踪攻击方向
- 正反打中，双方视线方向必须交叉匹配
- 第三人旁观时，视线指向正在交手的双方

### 能量守恒

- 轻击 → 轻微特效（衣料微震、小范围气流）
- 重击 → 明显特效（冲击波、碎片、地面裂纹）
- 必杀技 → 大范围特效（能量爆发、环境破坏），但需有蓄力过程
- 禁止轻击配大特效、重击无特效的不匹配情况

## 四、动作场景节奏模板

### 短打斗（3-4镜头）

```
镜头1：对峙/起势（1.5-2秒）→ 呼吸帧，积蓄张力
镜头2：交锋/高潮（2-3秒）→ 慢镜头强化关键打击点
镜头3：结果/余韵（1.5-2秒）→ 收势，环境反应
```

### 中等打斗（5-6镜头）

```
镜头1：对峙（1-1.5秒）→ 双方蓄势
镜头2：第一轮交锋（1.5-2秒）→ 快速剪辑
镜头3：呼吸帧（0.5-1秒）→ 双方调整，环境声突显
镜头4：第二轮交锋/高潮（2-2.5秒）→ 慢镜头强化
镜头5：追击/位移（1-1.5秒）→ 跟拍移动
镜头6：结果/余韵（1-1.5秒）→ 收势，环境恢复
```

### 长打斗（7-9镜头，方案G专用）

```
镜头1：环境/起势（1-1.5秒）→ 建立打斗空间
镜头2：试探交锋（1-1.5秒）→ 快速切
镜头3：呼吸帧（0.5-1秒）→ 调整站位
镜头4：主攻（1.5-2秒）→ 多角度，慢镜头打击点
镜头5：反击（1.5-2秒）→ 对方反击，节奏加快
镜头6：呼吸帧（0.5-1秒）→ 环境互动（碎石、尘土）
镜头7：高潮对决（2-2.5秒）→ 关键动作，升格+特效
镜头8：追击/位移（1-1.5秒）→ 跟拍+环境破坏
镜头9：结果/余韵（1-1.5秒）→ 收势，喘息，环境恢复
```
