# 景别库 📐

景别决定了观众与画面的"亲密距离"。**本技能为每个镜头提供景别、视角、焦点控制的选择依据**，确保镜头语言精准服务于情绪和叙事。

## 核心规则

1. **每个镜头必须从景别库中选择景别**，不得随意编造
2. **同组内避免连续使用同一景别**，相邻镜头景别应有差异，除非刻意制造重复节奏
3. **景别变化服务于情绪节奏**：从远景推至特写 = 情绪聚焦；从特写拉至远景 = 情绪释放
4. **视角必须配合景别使用**，每个镜头同时输出景别和视角
5. **焦点控制按需启用**，仅在需要引导注意力或制造视觉转换时使用

## 景别选择决策流程

面对任何镜头，**按以下顺序回答4个问题**，从景别库中选择最匹配的景别：

### 问题一：这个镜头需要观众看到多少信息？

- 全局环境、场景全貌 → **大远景 / 远景 / 全景**
- 人物与环境的关系 → **中全景 / 中景**
- 人物情感细节、面部表情 → **近景 / 特写**
- 极致微表情或物体极细节 → **大特写**

### 问题二：这个镜头的亲密距离是什么？

- 疏离（渺小、敬畏、孤独）→ **大远景 / 远景**
- 日常（平等、自然、对话）→ **中全景 / 中景**
- 亲密（情感聚焦、内心活动）→ **近景**
- 窒息（戏剧性、压迫、震撼）→ **特写 / 大特写**

### 问题三：景别变化是否服务于情绪节奏？

- 从远景推至特写 = **情绪聚焦**（拉近观众，画面从全局收束到面部细节）
- 从特写拉至远景 = **情绪释放**（抽离观察，人物在画面中越来越小，天地压顶）
- 从远景切到大特写 = **突然逼近**（画面瞬间填满面部，背景消失）
- 从大特写切到全景 = **空间揭示**（震惊反转，暴露环境真相）

### 问题四：从景别库中选择最匹配的景别

综合以上三个问题的答案，选择景别。若多个景别候选，选与上一镜头景别差异较大的那个（制造节奏变化）。

## 视角选择决策流程

选定景别后，**按以下顺序选择视角**：

### 第一步：权力关系

- 角色强势出场、英雄时刻 → **中等仰拍 / 强烈仰拍**
- 角色处于弱势、被围困、孤独 → **中等俯拍 / 强烈俯拍**
- 平等对话、日常叙事 → **平视**
- 反派、神圣角色、超现实 → **强烈仰拍 / 极端仰拍**

### 第二步：情绪强化

- 需要轻微强调角色 → **轻微仰拍**
- 需要表现渺小感或命运感 → **鸟瞰 / 强烈俯拍**
- 需要代入角色主观体验 → **主观视角**
- 需要制造紧张压迫 → **贴地角度**

### 第三步：视角与景别的配合

| 景别 | 推荐搭配视角 | 效果 |
|------|------------|------|
| 大远景 | 鸟瞰 / 平视 | 史诗氛围、全局展示 |
| 远景/全景 | 平视 / 轻微俯拍 | 空间交代、环境氛围 |
| 中景/中全景 | 平视 / 轻微仰拍 | 对话自然、关系展示 |
| 近景 | 平视 / 轻微仰拍 / 轻微俯拍 | 情感聚焦、内心活动 |
| 特写/大特写 | 平视 / 轻微俯拍 | 戏剧性、微表情捕捉 |

## 焦点控制触发条件

焦点控制**非每个镜头必用**，仅在以下情况触发：

### 触发条件一：引导注意力转移

- 焦点从前景移至后景 → 揭示环境、信息发现（如从手中的信切到写信的人）
- 焦点从后景移至前景 → 强调主体、意外效果（如从模糊背景切到突然出现的角色面部）

### 触发条件二：配合情绪转换

- 情绪平缓过渡 → **慢速焦点转移**（平滑、优雅）
- 注意力引导 → **中速焦点转移**（常用节奏）
- 突然揭示、震惊 → **快速 / 极速焦点转移**（戏剧性、视觉冲击）

### 触发条件三：配合景别转换

- 从远景推至特写的过程中，可叠加**慢速焦点转移**，前景从模糊到清晰，面部细节逐步显现
- 从特写拉至远景的过程中，可叠加**中速焦点转移**揭示环境

### 不触发的情况

- 对话正反打（焦点在两个说话者之间自然切换，不需要焦点控制）
- 固定机位静态镜头
- 快速剪辑的动作场景

## 画幅适配（全局规则）

**接收到画幅信息后，全局调整镜头描述逻辑**，而非仅调整景别选择：

### 9:16 竖屏

- **构图**：优先纵向构图，引导线纵向延伸，留白上下分布
- **调度**：转化为"前后错落"、"三角构图"或"大特写"
- **禁止**：横向一字排开
- **适合**：人物特写、竖向空间展示、手机端观看

### 16:9 横屏

- **构图**：默认画幅，电影构图，强调水平线条和层次感
- **调度**：利用左右空间展开调度，引导线横向延伸，对称左右分布
- **适合**：风景、场景建立、多人对话、电影级叙事
