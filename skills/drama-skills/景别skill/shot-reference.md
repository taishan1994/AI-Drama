# 景别库详细参考表

本文档提供景别、视角、焦点控制的完整定义和画幅适配规则，供创作时参考。

---

## 一、景别（从宽到窄，8级）

| 景别 | 拍摄范围 | 情绪意图 | 典型用法 |
|------|---------|---------|---------|
| 大远景 | 广阔场景，人物比例极小 | 渺小感、敬畏、史诗氛围、孤独 | 开场场景设定、宏大环境展示、人物与自然对比 |
| 远景 | 完整人物+周围环境 | 空间感、环境氛围、场景转换 | 展示人物与环境关系、场景转换、气氛营造 |
| 全景 | 完整人物全身+环境全貌 | 全面展示、空间定位、环境交代 | 人物全身入镜、展示空间关系、地理位置 |
| 中全景 | 人物全身+部分环境 | 人物与环境互动、空间定位 | 表现角色在环境中的位置和互动 |
| 中景 | 人物膝盖以上 | 均衡、对话、日常、关系展示 | 对话场景、情感交流、展示人物动作与环境 |
| 近景 | 人物胸部以上 | 亲密、情感聚焦、内心活动 | 面部表情特写、情感表达、重要台词、细微动作 |
| 特写 | 人物面部或物体局部 | 戏剧性、情感放大、细节强调 | 眼睛/嘴部/手部细节、道具象征、情感爆发瞬间 |
| 大特写 | 面部极局部（眼/唇）或物体极细节 | 窒息、极致亲密、压迫、震撼 | 瞳孔变化、泪珠、伤口细节、关键道具极细节 |

## 二、视角分类（辅助景别的角度选择）

| 视角 | 拍摄角度 | 情绪意图 | 典型用法 |
|------|---------|---------|---------|
| 平视 | 与眼睛齐平 | 平等、自然、客观 | 日常对话、客观叙事 |
| 轻微仰拍 | 略低于眼睛 | 轻微强调、自然效果 | 角色出场、轻微权威暗示 |
| 中等仰拍 | 低于胸部 | 威严、力量、敬畏 | 英雄出场、权力展示、角色强势时刻 |
| 强烈仰拍 | 接近地面 | 夸张、压迫、神圣 | 反派出场、神圣角色、科幻/奇幻场景 |
| 极端仰拍 | 贴近地面 | 超现实、视觉冲击 | 巨物仰望、极端情绪、特殊风格 |
| 轻微俯拍 | 略高于眼睛 | 轻微弱势、空间展示 | 角色犹豫、环境交代 |
| 中等俯拍 | 显著高于主体 | 孤立、脆弱、被审视 | 角色困境、孤独感、叙事过渡 |
| 强烈俯拍 | 高处俯瞰 | 绝望、渺小、全局观 | 角色被围困、战斗全局、命运感 |
| 垂直俯拍 | 正上方垂直 | 疏离、几何感、上帝视角 | 空间布局、人物关系构图、特殊风格 |
| 鸟瞰 | 高空俯瞰 | 宏观、全局、史诗 | 场景介绍、地理展示、戏剧性对比 |
| 主观视角 | 模拟角色视线 | 代入、沉浸、恐惧 | 第一人称体验、角色感知、运动模拟 |
| 贴地角度 | 接近地面 | 紧张、渺小、独特视觉 | 追逐场景、紧张感、特殊构图 |

## 三、焦点控制（辅助景别转换的视觉技巧）

| 技巧 | 操作方式 | 速度分级 | 情绪意图 |
|------|---------|---------|---------|
| 慢速焦点转移 | 焦点从前景平滑移至后景 | 慢速 | 平滑、优雅、情感过渡 |
| 中速焦点转移 | 焦点以中等速度切换 | 中速 | 注意力引导、信息揭示 |
| 快速焦点转移 | 焦点快速切换 | 快速 | 突然、戏剧性、震惊 |
| 极速焦点转移 | 焦点瞬间切换 | 极速 | 震撼、惊悚、视觉冲击 |
| 前景到背景 | 焦点从前景移至背景 | — | 揭示环境、信息发现 |
| 背景到前景 | 焦点从背景移至前景 | — | 强调主体、意外效果 |

## 四、画幅构图适配引擎

**根据当前确认的画幅，动态调整分镜描述逻辑：**

### 9:16 竖屏

- **纵向构图**为主
- 强制转化为"前后错落"、"三角构图"或"大特写"
- **禁止**"横向一字排开"
- 引导线纵向延伸、留白上下分布
- 适合：人物特写、竖向空间展示、手机端观看

### 16:9 横屏

- **默认画幅**，电影构图
- 强调水平线条、宽广视野和层次感
- 利用左右空间展开调度
- 引导线横向延伸、对称左右分布
- 适合：风景、场景建立、多人对话、电影级叙事
