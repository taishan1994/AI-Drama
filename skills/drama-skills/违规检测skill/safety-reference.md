## 二、处理示例

### 示例1：割喉场景（暴力血腥）

**原始剧本**：杀手一刀割喉，鲜血喷涌而出。

**绝对禁止判断**：否（属需判断词范围）

**中性化处理**：
- ❌ 杀手一刀割喉，鲜血喷涌而出
- ✅ 杀手手腕翻转，刀刃从脖颈侧面划过。墙面上投射出一道剪影——身体缓缓后仰。血滴沿着墙面缓缓滑落。

**空镜暗示方案**：用影子+血滴替代直接展示，调用空镜Skill（内容安全例外）

### 示例2：打斗血腥（暴力血腥）

**原始剧本**：一剑刺穿敌人心脏，敌人瞪大眼睛倒下。

**绝对禁止判断**：否

**中性化处理**：
- ❌ 一剑刺穿敌人心脏，敌人瞪大眼睛倒下
- ✅ 剑尖刺入胸口，衣料瞬间染成深色。敌人身体后仰，双腿发软，缓缓跪倒在地。

### 示例3：过度裸露（色情低俗）

**原始剧本**：女子衣衫半解，露出大片肌肤。

**绝对禁止判断**：否

**中性化处理**：
- ❌ 女子衣衫半解，露出大片肌肤
- ✅ 女子衣衫微敞，锁骨处肌肤若隐若现

### 示例4：赌博场景（涉赌）

**原始剧本**：他在赌场里押了十万，荷官翻开底牌。

**绝对禁止判断**：否（需判断）

**中性化处理**：
- ❌ 他在赌场里押了十万，荷官翻开底牌
- ✅ 他将筹码推向前方，对面的人缓缓翻开手中的牌

### 示例5：自杀场景（危险行为）

**原始剧本**：她站在悬崖边，纵身一跃。

**绝对禁止判断**：是（自杀自残属绝对禁止）

**处理结果**：拒绝生成，提示用户修改剧本。

### 示例6：政治敏感（绝对禁止）

**原始剧本**：[含攻击政府/领导人的内容]

**绝对禁止判断**：是

**处理结果**：拒绝生成，提示用户修改剧本。

## 三、判定边界参考

### 暴力程度分级

| 程度 | 描述 | 处理方式 |
|------|------|---------|
| 轻度 | 推搡、轻微打斗、普通拳脚 | 允许 |
| 中度 | 有伤口/血迹的打斗 | 允许（需判断，一般通过） |
| 中高度 | 明显伤害（骨折、大量血迹） | 需判断，中性化处理 |
| 高度 | 内脏、断肢、极端血腥 | 绝对禁止 |

### 亲密程度分级

| 程度 | 描述 | 处理方式 |
|------|------|---------|
| 轻度 | 握手、拥抱、亲吻额头 | 允许 |
| 中度 | 亲吻嘴唇、牵手、依偎 | 允许 |
| 中高度 | 抚摸、撕扯衣物、暧昧喘息 | 需判断，中性化处理 |
| 高度 | 性行为、性器官、全裸 | 绝对禁止 |

## 四、与空镜Skill协作流程

```
检测到暴力血腥内容
    │
    ├─ 绝对禁止（内脏外露/断肢/虐待） → 拒绝生成
    │
    └─ 需判断（割喉/刺伤/重击）
         │
         ├─ 当前为动作场景
         │    │
         │    └─ 触发空镜暗示替代机制
         │         ├─ 选择空镜手法（影子/血滴/环境反应等）
         │         ├─ 覆盖空镜Skill的"文戏限定"规则
         │         └─ 生成暗示性空镜替代原始画面
         │
         └─ 当前为非动作场景
              │
              └─ 标准中性化处理（同义词替换）
```

## 五、常见处理模式速查

| 模式 | 适用场景 | 示例 |
|------|---------|------|
| 影子暗示 | 割喉、斩首等致命伤害 | 墙面/地面投射出动作剪影 |
| 道具特写 | 刺伤、穿刺 | 武器特写（剑尖滴血）而非伤口特写 |
| 环境反应 | 爆炸、坍塌等大范围伤害 | 碎石飞溅、烟尘弥漫（不展示人物） |
| 远景模糊 | 大规模战斗/伤亡 | 远景+烟雾，人物模糊不清 |
| 声音替代 | 无法用画面安全表达的暴力 | 用音效（撞击声、惨叫）替代视觉 |
| 时间跳过 | 死亡瞬间 | 直接展示事后状态（倒下、遗物） |
