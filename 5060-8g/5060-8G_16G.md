我的机器是5050-8G+16G内存，cuda 版本是13.1。

到[适用于 Windows 的 ComfyUI 便携版 - ComfyUI](https://docs.comfy.org/zh/installation/comfyui_portable_windows) 

找到：

![image-20260929222118884](5060-8G_16G%20%5B2%5D.assets/image-20260929222118884.png)

一般情况下，cuda向下兼容，因此这里我选择的是cuda 13.0版本的下载。下载完成后进行解压即可。

![image-20260929222222989](5060-8G_16G%20%5B2%5D.assets/image-20260929222222989.png)

python_embeded里面有python环境，用于启动comfyui，这样就不用我们去安装python环境了。

ComfyUI/models下面就存放着各种模型（需要自己下载到对应的文件夹下）。

ComfyUI/output下是工作流完成之后生成的视频会存放在这里，

ComfyUI/input下是工作流中你上传的素材会存放在这里。

启动comfyui：

```bash
进入到ComfyUI文件夹，在终端执行：
..\python_embeded\python.exe main.py --windows-standalone-build --lowvram --fp16-vae --disable-pinned-memory

看到：
[INFO] Context impl SQLiteImpl.
[INFO] Will assume non-transactional DDL.
[INFO] Using RAM pressure cache.
[INFO] Starting server

[INFO] To see the GUI go to: http://127.0.0.1:8188

说明启动成功
```

在浏览器输入： http://127.0.0.1:8188 ，即可打开comfyui界面
