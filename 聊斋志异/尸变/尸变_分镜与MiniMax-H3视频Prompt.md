# 《尸变》分镜与 MiniMax-H3 视频 Prompt

## 统一执行规则

- 画幅 `16:9，1344×768`，单镜 4–8 秒；统一中国经典手绘动画：二维平涂、水墨宣纸肌理、墨线、低饱和靛青灰与琥珀灯，不要写实、3D、日漫。
- `参考图`：加载环境锚点，必要时再加载人物设定板；`首尾帧`：沿用已审核镜头尾帧；`文生`：仅用于没有连续人物的建立镜头。
- 每条 Prompt 都追加：`没有字幕、题字、水印、现代物件；无额外人物、无脸部变形、无克隆人物。`
- 无对白镜头追加：`无旁白、无音乐、无人声、无动物声；只保留指定环境声。`
