# 《瞳人语》分镜与 MiniMax-H3 Prompt 基线

## 固定视觉规则

上美影式中国经典手绘动画：二维赛璐璐平涂、手工墨线、宣纸与水彩肌理、低饱和青灰和赭褐色块、舞台化景深。春郊使用淡青、嫩绿、暖金；室内使用旧木褐、灰青和少量烛火。禁止照片级皮肤、3D材质、日漫大眼、现代物件、随机新增人物、镜头炫光和血腥写实。

## 通用 H3 Prompt 模板

```text
上美影式中国经典手绘动画，二维赛璐璐平涂，手工墨线，宣纸水彩肌理，低饱和中国古代场景，保持角色设定板与上一镜尾帧完全一致。严格保持人物数量、年龄、服装、发型、空间位置和镜头方向。按起始状态到结束状态完成连续动作，不瞬移，不新增人物，不改变门窗桌案位置，不改变脸型。

【角色】方栋：瘦削成年书生，黑色儒生幞头，深青长袍，短须；妻子：固定发式与素色衣裙；瞳人：豆粒大小微型人形，青灰/金白两种色调，比例始终微小，不得变成人类大小。
【镜头动作】<填写该镜头卡的动作链>
【空间锚点】<填写主空间图中的门、窗、桌案、床榻或车队位置>
【首帧】<上一镜尾帧/首张资产>
【尾帧】<本镜结束状态>
【声音】<旁白/角色对白/环境声的唯一清单>
【禁止】额外人声、狗叫、音乐、随机对白、角色变脸、人数变化、空间漂移、动作断裂、血腥写实、3D和照片感。
```

## 资产生成顺序

1. 角色板：方栋、妻子、贵女、婢女、瞳人甲、瞳人乙；人物图四分格，左侧头像主体，右侧为正/侧/背三视图。
2. 主空间图：春郊道路与唯一车队、方栋书房、夜间书房/书案、铜镜和经卷。
3. 特效资产：眼部薄翳、右眼旋螺、两个豆粒瞳人从鼻孔中心出现的首尾帧；特效必须保留手绘线条，不用粒子爆炸。
4. 每个镜头先生成首尾帧资产，确认后再提交 H3 视频；下镜头首帧优先取上镜头验收尾帧。

## 声纹登记

- 方栋：成年男书生，前期轻佻好奇，后期低沉悔悟。
- 妻子：成年女声，克制、关切，不尖叫。
- 婢女：年轻女声，短促、凌厉。
- 瞳人甲：细小、清亮、谨慎。
- 瞳人乙：细小、偏低、灵巧。
- 旁白：平静、古雅、无情绪抢戏。

每条对白先单独生成并试听，再与环境声混合；视频生成后用 ASR 解析最终音轨生成字幕。

## 前三镜头叙事验收修订

现有 S01–S03 版本未通过叙事验收：虽然表现了“看到车队—跟随—婢女斥责”，但没有把方栋的窥视对象、主动靠近和车内外视线交汇拍清楚。修订版必须至少出现三个可核对的视觉证据：

1. 方栋停步回头，眼神明确落在车帘；
2. 方栋主动追近并探头寻找车帘缝隙；
3. 贵女先发现视线，婢女顺着贵女目光看见方栋后才斥责。

在前三镜头通过前，不得进入 S04A；S04A 必须先完成真实下车和取土，S04B 才能出现扬尘与方栋受伤反应。

## S04 物理逻辑修订

婢女不能坐在车厢内直接抓取道路尘土。修订后必须保持：车队短暂停下→婢女从踏板下车→在车轮旁取土→站在车外向方栋扬尘。贵女始终留在车内，不能跟着下车；婢女的手、脚和车厢踏板必须有清楚接触关系。

本次拆镜修订：将原 S01 拆为 S01A 与 S01B。验收顺序改为：S01A 发现车队，S01B 侧脸窥看车帘，S02 主动尾随并寻找帘缝，S03 由贵女先察觉、婢女再斥责。原 S01–S03 成片全部降级为测试样片。
