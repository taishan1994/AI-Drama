# 《山魈》高潮重制版分镜与 MiniMax-H3 Prompt 计划

## 统一锁定

- 真人电影质感，南山柳沟寺书斋；1344×768、24fps；不超分。
- 永久锚点：书案与油灯左侧、纸窗左后、中央木门、床榻右侧。
- 所有镜头必须写明人物数量、进入方向、离开方向和不可出现对象。
- S01 冷开场直接给出门闩、被角和爪痕；S09 是全片动作高潮；S12 留反转。
- 生成底片禁止字幕、logo、水印；对白和字幕在最终音轨验收后处理。

## H3 Prompt 共同约束

每镜使用 `subject_definitions / summary / retention_analysis / detailed_description / overall_soundscape / non_diegetic_music` 六段格式。所有镜头追加：`preserve fixed room geometry; no extra people; no open center door unless explicitly stated; no subtitles, logos, watermarks, modern objects, or music`。S01、S08、S09、S12 必须使用门、被角和爪痕关键帧参考，避免高潮动作被模型简化成普通站立。

## 生成顺序

先生成并验收 S01、S08、S09 三个高潮关键镜头，再生成 S02–S07 的铺垫，最后生成 S10–S12 的证据与反转。每个镜头抽取开头、中点、结尾三帧；任何人物数量、门闩状态或爪痕位置不一致，都不得进入拼接。
